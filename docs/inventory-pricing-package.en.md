# Internal Inventory Management System - Monthly Package and Add-on Pricing

**RM79/month Basic Package**

Note: This document is a package recommendation. Pricing and scope can be adjusted based on customer industry, SKU count, warehouse count, and customization requirements.

## Inventory Ordering System Pricing Package

**Basic Package RM79/month + optional add-ons as needed**

Positioning: An internal inventory system for small shops, warehouses, online stores, and F&B businesses. Staff update stock quantities daily, while owners can check low-stock alerts anytime from mobile or desktop and order from suppliers with one-click WhatsApp.

## 1. Basic Package - RM79/month

| Item | Included |
| --- | --- |
| Accounts | 1 Admin login + 1 Staff login |
| SKU Count | Includes 500 SKUs |
| Warehouse / Store | Includes 1 warehouse / store / inventory location |
| Low Stock Alert | Set a minimum stock quantity. If stock drops below the configured quantity, the system shows that restocking is needed. |
| Supplier Information | Record supplier name and phone number, with a WhatsApp Supplier button. |
| SKU Photos | Each SKU can have a product photo to help staff identify items. |
| Inventory Operations | Staff can Add Stock / Deduct Stock, and owners can view inventory changes. |
| Stock Movement History | Records who added/deducted stock, when it happened, quantity changed, and notes. |
| Usage | Usable on both mobile and desktop. |

## 2. Add-on Pricing Table

| Add-on | Price | Description |
| --- | --- | --- |

| Excel Import / Export | +RM20/month | Allows customers to import/export product and inventory data themselves. |
| Barcode Scanner | +RM30/month | Suitable for warehouses, wholesale, grocery, pet shops, and other businesses that need scanning operations. |
| Expiry Date Reminder | +RM20/month | Suitable for food, beauty, pharmacy, frozen food, and other products with expiry dates. |
| Advanced Report | +RM30/month | Includes more detailed inventory reports, staff operation statistics, low-stock reports, exported reports, and related reporting features. |
| Advanced Permission | +RM20/month | More granular permission control, such as limiting staff to specific warehouses or allowing only add/deduct stock actions. |
| Stock Transfer | +RM30/month | Used for stock movement between warehouses/branches. The system automatically deducts from one location, adds to another, and records the operation. |

## 3. Setup Fee and Data Import Service

| Item | Recommended Price | Included / Description |

| Setup Fee | RM299 one-time | Account setup, basic configuration, one training session, and import of up to 50 SKUs. |
| Data Import Service | From RM100 / session | Charged when import exceeds the 50 SKUs included in setup, or when customer data is messy and requires Excel cleanup. |

## 4. Important Recommended Limits

| Item | Recommended Rule |
| --- | --- |
| Staff Login | If there are more than 20 staff accounts, recommend moving to a Business / Custom Plan because support and permission management will increase. |
| SKU Count | Basic Plan is recommended up to 3,000 SKUs. Above 3,000 SKUs, recommend Warehouse / Custom Quote. Above 10,000 SKUs should not use standard pricing and should be quoted as Custom. |
| Warehouse / Branch | Adding a warehouse only adds an inventory location. If the customer needs transfer between warehouses, Stock Transfer must be purchased separately. |
| Custom Features | Monthly fee only includes standard system usage and maintenance. Special features must be evaluated and quoted separately. |

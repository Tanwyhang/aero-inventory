## 库存订货系统收费配套

**Basic Package RM79/月 + 按需求加购 Add-on**

定位：给小店、仓库、网店、餐饮店使用的内部库存系统。员工每天 update 数量，老板手机/电脑随时看到低库存提醒，并可一键 WhatsApp supplier 订货。

## 1. Basic Package - RM79/月

| 项目 | 包含内容 |
| --- | --- |
| 账号 | 1 个 Admin login + 1 个 Staff login |
| SKU 数量 | 包含 500 个 SKU |
| 仓库 / 店面 | 包含 1 个仓库 / 店面 / 库存地点 |
| Low Stock Alert | 可设置最低库存数量，低过指定 qty 会显示需要进货 |
| Supplier 资料 | 可记录 supplier 名字、电话号码，并支持 WhatsApp Supplier 按钮 |
| SKU 照片 | 每个 SKU 可以上传产品照片，方便员工辨认 |
| 库存操作 | 员工可以 Add Stock / Deduct Stock，老板可以查看库存变化 |
| Stock Movement History | 记录谁在什么时候加/减库存、数量和备注 |
| 使用方式 | 手机和电脑都可以使用 |

## 4. 重要限制建议

| 项目 | 建议规则 |
| --- | --- |
| 员工 login | 超过 20 个员工账号，建议进入 Business / Custom Plan，因为 support 和权限管理会增加。 |
| SKU 数量 | Basic Plan 建议最多加到 3,000 SKU。超过 3,000 SKU 建议升级 Warehouse / Custom Quote。10,000 SKU 以上不要用普通价，建议 Custom Quote。 |
| 仓库 / 分店 | 加仓库只是增加库存地点；如果客户要仓库之间转货，需要另外购买 Stock Transfer。 |
| 客制功能 | 月费只包含标准系统使用和维护；特别功能必须另外评估和报价。 |

## 6. 对客户的简单销售文案

RM79/月基础库存系统，适合小店、仓库、网店和餐饮店使用。员工可以每天更新库存，老板随时查看低库存提醒，并可一键 WhatsApp supplier 订货。基础版包含 1 Admin、1 Staff、500 SKU、1 仓库、Low Stock Alert、Supplier 电话、WhatsApp Supplier、产品照片和库存加减记录。需要更多员工、SKU、仓库或特别功能，可以按需求加购。

备注：以上价格适合初期产品定位。后续可根据客户数量、服务器成本、support 成本和市场反应调整。
